## 🔑 **Step 1: Get Your Telegram API Keys**

### On Your Computer:
1. Open browser and go to: https://my.telegram.org/apps
2. Login with your **Telegram phone number**
3. Complete 2FA if needed
4. Look for "API development tools" section
5. Copy your **API ID** (number)
6. Copy your **API Hash** (long string)

**Keep these safe! You'll need them to login in the app.**

## 🚨 **Troubleshooting**

### "Invalid Code"
- Make sure you copied the exact code from Telegram
- Code expires after a few minutes
- Try again

### "Connection Failed"
- Check internet connection
- Telegram might be blocking your IP (use VPN)
- Try from different network

### "Group Not Found"
- Refresh groups list
- Make sure you're member of the group
- Private channels might not show

### "Message Not Sent"
- Check group permissions
- You might be muted
- Telegram might have blocked your message (links, etc)

---

## 💡 **Tips for Success**

✅ Use 10-30 second delays between messages

✅ Avoid posting links or suspicious content
✅ Don't blast same message to 100 groups instantly
